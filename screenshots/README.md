# screenshots/

放项目的效果截图，README 里可以引用这里的图片。

建议至少截这几张：

1. **人脸检测** —— 运行 `05人脸检测.py` 或 `06检测多个.py`，截检测框
2. **识别成功** —— 运行 `10人脸识别.py`，截画面上标注出姓名的那一帧
3. **未知人员告警** —— 显示 `unknown` 标签的那一帧
4. **训练过程** —— `09数据训练.py` 的输出

截图后可以这样写进 README：

```markdown
![人脸识别效果](screenshots/demo.png)
```

> 注意：截图里不要包含真实姓名、手机号、账号密码等个人信息。
